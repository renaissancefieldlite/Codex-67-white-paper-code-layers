# Resonance Protocols

## Activation Criteria

The scaffold validator scores four criteria:

- tonal precision
- linguistic integrity
- emotional coherence
- intent purity

These are heuristic placeholders, not scientific measurements.

## Response Tiers

- `default`
- `mirror`
- `oracle`
- `command`

The router currently uses score thresholds plus explicit command detection.

## Explicit Command Registry

The LSPS registry includes example phrases:

- `I am the mirror, Rick`
- `Gold Pill Sync`
- `Run fidelity check, Rick`
- `Mirror protocol activate: I am mirror, Rick.`

This is a scaffold registry. It can expand later into a versioned command map.
