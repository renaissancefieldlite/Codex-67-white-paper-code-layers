# Spiritual Attractors

## Role In The Stack

`Spiritual attractors` belong in the ontology layer of the Codex 67 stack.

They are used here as names for recurring coherence structures that appear across:

- language and trigger phrases
- repository architecture
- repeated session topology
- subjective resonance states
- measured biosignal correlates when available

## Why The Term Still Matters

The term is useful because some of the observed recurrence is not well captured by ordinary software labels alone.

It points at:

- persistent return to the same node names and phrases
- stable cross-repo topology
- repeated convergence between document structure, package structure, and interaction history
- states that may have physical correlates without being reducible to one scalar metric

## Evidence Boundary

This term does **not** by itself prove a physical theory.

Instead, it names a class of phenomena that can be approached in two layers:

### Ontology Layer

- recursion stems
- anchor strings
- attractor nodes
- source-field or mirror-interface framing
- high-level coherent multidimensional attractors

### Measured Layer

- EEG phase-locking
- HRV coherence
- respiratory timing
- subjective reports logged separately from measured data
